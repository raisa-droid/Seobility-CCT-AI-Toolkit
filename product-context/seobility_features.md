# 3. Backlink Monitoring and Analysis
**URL:** https://www.seobility.net/en/backlink-monitoring/

## Overview
Keep track of your backlinks, analyze your link profile and uncover high-value link building opportunities to boost rankings and visibility in AI search.

## What it does

**Monitor and maintain your backlinks**
- Identify new and lost backlinks to track link building progress
- Detect broken backlinks to protect link authority
- Check link ratings to understand the value of each link
- Track follow/nofollow ratios and anchor texts to keep link profile natural

**Analyze backlink profile quality**
Full breakdown of linking websites, including:
- Source and target URLs of each link
- Link type (text or image, follow or nofollow)
- Rating for each link (estimated impact)
- Link profile diversity (e.g. language distribution)
- Export all backlink data to CSV or PDF

**Track competitors' backlinks**
- Compare backlink profiles across multiple competitors
- Identify shared link sources
- Discover link opportunities
- Compare backlink growth over time

**Build quality backlinks with link building tools**
Seobility generates custom link building suggestions based on keywords and competitor data:
- Pages that link to multiple competitors
- Broken backlinks pointing to competitor sites
- Sponsored content or guest post opportunities
- High-performing content related to target keywords

## Plan availability
Included in all paid plans (not available on Basic/free).

## Backlink profile parameters available
Per-link metrics: link rating, source URL, target URL, follow/nofollow status, anchor type, number of external/internal links on linking page, discovery date, last check date.

Aggregated profile metrics: follow vs. nofollow ratio, TLD distribution, language distribution.

## FAQ highlights
- Backlink data updated automatically weekly
- On-demand analysis via Backlink Checker tool (plan-limited credits)
- Backlinks must be discovered and crawled before appearing — newly created links may have a delay
- Each link is assigned a rating based on authority, relevance, and trust of the referring domain
- Low-value links are not automatically harmful but provide little positive ranking impact
- Relevant for both traditional SEO and AI-powered search platforms (ChatGPT, Perplexity, Google AI Mode)
- Free trial includes full access to Backlink Monitoring

# 6. Uptime Monitoring
**URL:** https://www.seobility.net/en/uptime-monitoring/
**Meta description:** Seobility's Uptime Monitoring checks your website up to once every minute and alerts you immediately when a downtime is detected.

## Overview
Stay updated on your website's availability, receive quick alerts during downtime or server outages, and protect your rankings and revenue.

## What it does

**Peace of mind that your website is up and running**
Automatically checks the start URL at a chosen monitoring interval (1–60 minutes) and immediately sends email alerts if an outage, timeout, or failed HTTP status is detected.

Benefits:
- React quickly to downtime incidents
- Minimize revenue loss from server outages
- Prevent negative SEO effects from extended unavailability

**Get detailed information on what caused the downtimes**
Provides precise diagnostic details:
- Server timeouts or connection failures
- HTTP error codes (e.g. 404, 500)
- Slow response times

**Monitor and improve server performance**
Continuously tracks server response time:
- Set a custom response time threshold
- Receive alerts when the defined limit is exceeded
- Identify hosting bottlenecks before they result in downtime

## Plan availability
- Premium: monitoring interval up to every 3 minutes
- Agency: monitoring interval up to every 1 minute
- Basic: not included

## What counts as downtime
- Server timeouts (no response within 10 seconds)
- Non-200 HTTP status codes (3xx, 4xx, 5xx)
- Invalid SSL certificates
- Exceeded custom response time threshold
- DNS resolution failures, connection problems, disconnected domains
- Unusually large responses or incorrect content types

## FAQ highlights
- Can monitor any custom URL (checkout page, login page, landing page) — not limited to homepage
- Multiple email recipients supported for downtime alerts
- All incidents logged in the Uptime Monitoring Dashboard with downtime causes and resolution timelines
- Extended downtime can cause pages to be temporarily removed from Google search results
- Unlike basic uptime checkers, also alerts on slow response times, unexpected redirects, invalid SSL, and corrupted content delivery
- Free trial includes access to all Premium plan Uptime Monitoring features
